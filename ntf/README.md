# QQC电子钱包 - H5原型设计

## 项目概述

这是一个高保真的H5电子钱包原型，模拟了完整的数字货币钱包功能，包括资产管理、NFT认购、质押挖矿、邀请体系和用户中心等核心功能。

## 功能特性

### 🏠 首页 (Home)
- **资产总览面板**: 实时显示QQC余额、NFT持仓价值、累计收益
- **快捷操作区**: 一键跳转认购、质押、邀请功能
- **公告轮播**: 重要系统通知和活动信息
- **行情看板**: QQC/USD实时价格和走势图
- **最近活动**: 显示用户最近的操作记录

### 💰 转账页面 (Transfer)
- **转账表单**: 收款地址输入、转账金额设置、币种选择
- **扫码转账**: 扫描二维码快速转账
- **手续费显示**: 实时显示网络手续费
- **转账记录**: 最近转账历史记录
- **快速转账**: 通讯录、分享收款等功能

### 📥 收款页面 (Receive)
- **收款二维码**: 生成收款二维码和地址
- **币种选择**: 支持多种币种收款
- **分享功能**: 社交媒体分享收款地址
- **收款统计**: 累计收款金额、次数、平均金额
- **收款设置**: 通知设置、安全验证、自动确认

### 🖼️ NFT页面 (NFT)
- **NFT展示墙**: 个人NFT收藏展示
- **筛选功能**: 按收藏、交易、创建分类
- **NFT统计**: 总数量、总价值、收藏数量
- **NFT管理**: 收藏、交易、创建NFT
- **价值追踪**: 显示NFT价值变化

### 👤 个人中心 (Profile)
- **资产仪表盘**: 资产分布饼图、收益趋势折线图
- **交易记录**: 多维度筛选、链上交易ID链接、CSV导出
- **安全中心**: 二步验证设置、设备管理、交易密码修改
- **系统设置**: 语言设置、深色模式、清除缓存

## 技术栈

- **HTML5**: 语义化标签，响应式布局
- **Tailwind CSS**: 现代化CSS框架，快速样式开发
- **Font Awesome**: 丰富的图标库
- **Lucide**: 现代化图标库
- **Unsplash API**: 高质量图片资源

### 🎨 UI设计
- **现代化界面**: 采用渐变色彩、圆角设计、阴影效果
- **iPhone 15外观**: 模拟真实手机界面，包含状态栏和底部导航

### 🔧 功能完整性
- **完整流程**: 从注册到交易的完整用户旅程
